# Shifty

A shift management application designed to simplify employee scheduling, 
shift planning, and workforce coordination.

## About the Project

Shifty is a planned shift management application that aims to make 
organizing work schedules easier for both administrators and employees.

The application will provide tools for creating and managing work shifts, 
tracking employee availability, handling leave requests, exchanging shifts, 
and monitoring working hours.

## Main Features

### 1. Shift Planning and Customization
Administrators will be able to define the required number of employees 
and working hours for each day. They will also be able to view employees 
who are available for work.

### 2. Weekly Shift Templates
The application will provide an interactive calendar that will allow 
administrators to create and manage weekly shift templates.

### 3. Shift Registration
Employees will be able to browse the schedule and sign up for their 
preferred shifts.

### 4. Leave and Sick Leave Requests
Employees will be able to request vacation days or report sick leave. 
Once approved by an administrator, their working hours and availability 
will be updated automatically.

### 5. Automatic Schedule Updates
The application will dynamically respond to changes and automatically 
update the schedule when relevant information changes.

### 6. Manual Schedule Management
Administrators will be able to manually add, remove, or reassign 
employees to specific shifts.

### 7. Shift Exchange Requests
Employees will be able to submit shift exchange requests. Other employees 
will be able to accept or reject these requests.

### 8. Monthly Working Hours Reports
The application will record completed shifts and generate monthly 
summaries of working hours for each employee, including vacation and 
sick leave records. Reports will be exportable as PDF files.

### 9. Clock In and Clock Out
Employees will be able to record the beginning and end of their shifts 
using dedicated buttons in the application.

### 10. Announcements and Tasks
The application will include a dedicated notice board where administrators 
can publish announcements for all employees. Administrators will also 
be able to assign individual tasks to employees for specific shifts.

## User Roles

- **Administrator:** Responsible for managing employees, schedules, 
  requests, announcements, and reports.
- **Employee:** Able to view schedules, sign up for shifts, submit 
  requests, track working hours, and view assigned tasks.

## Technologies
The application is planned to be developed using the following technologies:

- **Development Framework:** Flutter
- **Programming Language:** Dart
- **Database and Backend Services:** Firebase (cloud services and user authentication)
- **PDF Report Generation:** Printing package from [pub.dev](https://pub.dev/packages/printing)
