# User Stories

This document contains the user stories for the Shifty application. Each user story describes a feature from the perspective of the user who will use it and explains its purpose.

## Administrator

1. As an administrator, I want to enter my business information during registration so that I can create a profile for my hospitality business.

2. As an administrator, I want to generate a QR code for my business so that employees can easily join the company.

3. As an administrator, I want to approve or reject employee requests to join the company so that I can control who has access to the company's information.

4. As an administrator, I want to remove an employee from the company so that they can no longer access the company's information.

5. As an administrator, I want to view the working hours of all employees so that I can keep track of the work performed.

6. As an administrator, I want to view the working hours of an individual employee so that I can check their work records.

7. As an administrator, I want to create a weekly schedule template so that I can define the usual organization of work.

8. As an administrator, I want to see how many employees are available for each shift so that I can identify shifts that are not fully staffed.

9. As an administrator, I want to receive a warning when a shift does not have enough employees so that I can take action in time.

10. As an administrator, I want to export a monthly overview of all employees' working hours to a spreadsheet so that I can use the data for payroll calculations.

## User

11. As a user, I want to reset my forgotten password so that I can regain access to my account.

12. As a user, I want to edit my personal information so that my details in the application are always up to date.

## Employee

13. As an employee, I want to enter my availability in the interactive calendar so that the administrator knows when I am available to work.

14. As an employee, I want to receive a notification when the schedule is published so that I know my upcoming work shifts in time.

15. As an employee, I want to submit a day-off request so that the administrator knows when I am unable to work.

16. As an employee, I want to report sick leave so that the administrator knows I cannot work my scheduled shift.

17. As an employee, I want to submit a shift exchange request so that I can find a colleague to take over my shift.

18. As an employee, I want to see the number of hours I have worked each day so that I can keep track of my working time.

19. As an employee, I want to view my working hours history so that I can check my previous work records.

20. As an employee, I want to view my colleagues' schedules so that I know who is working the same shift as me.
